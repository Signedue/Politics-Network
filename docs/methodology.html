Methodology

Each decision below is tied to a documented diagnostic or validation report.

01 / QUESTIONCan individual votes be retrieved reliably?

Test: Folketinget's official OData service was inspected and one vote was retrieved.

Result: OData initially returned 100 rows; odata.nextLink revealed additional pages. Vote 2 contained 179 individual records: 59 For, 51 Imod, and 69 Fravær. Cast-vote totals matched the official result.

Decision: Automatically follow OData pagination. PASS

02 / QUESTIONHow much of period 20251 has individual data?

Test: Count-only queries were made for all Afstemning records.

Result: 192 records were identified; 168 had individual Stemme data and 24 had zero individual rows. Coverage was 87.5%, with missing votes clustered in two meetings.

Decision: Use only the 168 observed votes and document the 24 unavailable votes. These observed votes are not described as a random sample. PASS

03 / QUESTIONHow should pairwise agreement be defined?

Test: Similarity was defined as the same participated voting positions divided by shared participated votes. Fravær and missing observations were excluded.

Result: In the 10-vote test, similarity of 1.0 could be based on only one shared vote.

Decision: Always retain n_shared alongside similarity. PASS

04 / QUESTIONHow many votes are needed?

Test: Pairwise diagnostics progressed from 10 votes to 50 votes to all 168 valid votes.

Result: The median n_shared was 12 for 50 votes and 40 for 168 valid votes. First-half versus second-half similarity correlation was 0.8984 for eligible pairs.

Decision: Use all 168 valid votes for pairwise estimation. PASS

05 / QUESTIONIs raw similarity above vote-level expectations?

Test: For each vote, participation, absence, missingness, and exact For / Imod / Hverken totals were fixed while positions were shuffled across participating politicians.

Result: Observed mean similarity was 0.741 and null mean similarity was 0.747. Same-party mean excess was +0.254; different-party mean excess was -0.049.

Decision: Raw similarity alone is insufficient; use excess similarity relative to the vote-preserving null. This is not a causal claim. PASS

06 / QUESTIONWhat provisional agreement network is defensible?

Test: Require participated votes ≥ 40, pairwise n_shared ≥ 40, excess similarity > 0, and Benjamini-Hochberg adjusted q < 0.05. Use excess similarity as the edge weight.

Result: The provisional Rule B network has 150 politicians, 3,086 edges, 147 nodes with edges, 3 isolates, 6 components, and a 117-node giant component. Rule B versus Rule C edge Jaccard was 0.9802.

Decision: Use Rule B as a provisional, validated network definition for diagnostics. It was preferred to uncorrected p-values, arbitrary global cutoffs, and highly parameter-sensitive disparity filtering. PASS

07 / QUESTIONAre communities stable and above the null baseline?

Test: Weighted Louvain was run with 20 seeds on all 150 nodes. A degree-preserving edge-swap null retained the degree sequence while randomly permuting observed edge weights across shuffled edges.

Result: Every run found 9 communities; modularity ranged from 0.1366 to 0.1531, with mean pairwise NMI 0.9623. The representative seed was 1004 with Q = 0.1530. The null mean Q was 0.0630, SD 0.00229, z = 39.32, and empirical p = 0.00990. Community/party NMI was 0.6449; Rule B/Rule C community NMI was 0.9085.

Decision: The voting-agreement network contains stable community structure beyond the chosen null baseline. Communities partly align with formal party labels but are not identical to them. PASS
